Simply Supported Beam — Theory

System

A simply supported beam rests on a pin at A and a roller at B. It is statically determinate — 3 equilibrium equations are sufficient.

Reactions

ΣF_y = 0 → A + B = ΣFᵢ·cos(αᵢ) + ΣqᵢLᵢ
ΣM_A = 0 → B·L = ΣFᵢ·cos(αᵢ)·aᵢ + Σqᵢ·Lᵢ·x̄ᵢ

Shear Force Q(x)

Q(x) = A − ΣFᵢ·cos(αᵢ)·H(x−aᵢ) − Σqᵢ·⟨x−aᵢ⟩
H = Heaviside, ⟨·⟩ = Macaulay bracket

Bending Moment M(x)

M(x) = A·x − ΣFᵢ·cos(αᵢ)·⟨x−aᵢ⟩ − Σqᵢ·⟨x−aᵢ⟩²/2
Tension-bottom: positive M shown downward

Inclined Loads

F_y = F·cos(α)  → Q, M
F_x = F·sin(α)  → N (normal force)
Cantilever — Theory

System

A cantilever is fully fixed at A (moment, shear, normal) and free at the other end. It is statically determinate.

Reactions at A

V_A = ΣFᵢ·cos(αᵢ) + ΣqᵢLᵢ
H_A = ΣFᵢ·sin(αᵢ)
M_A = ΣFᵢ·cos(αᵢ)·aᵢ + Σqᵢ·Lᵢ·x̄ᵢ

Shear Force & Moment

Q(x) = V_A − ΣFᵢ·cos(αᵢ)·H(x−aᵢ) − Σqᵢ·⟨x−aᵢ⟩
M(x) = −M_A + V_A·x − ΣFᵢ·cos(αᵢ)·⟨x−aᵢ⟩ − Σqᵢ·⟨x−aᵢ⟩²/2
Continuous Beam — Theory

Static Indeterminacy

A continuous beam with n spans has (n−1) intermediate supports. Each extra support introduces one additional unknown reaction, making the system statically indeterminate to the (n−1)th degree. Equilibrium alone is not sufficient — compatibility of deformations must also be satisfied.

Three-Moment Equation (Clapeyron)

For each intermediate support i, the compatibility condition relates the moments at supports i−1, i, and i+1:

Mᵢ₋₁·Lᵢ + 2Mᵢ·(Lᵢ+Lᵢ₊₁) + Mᵢ₊₁·Lᵢ₊₁ = −6·(Aᵢ·āᵢ/Lᵢ + Aᵢ₊₁·b̄ᵢ₊₁/Lᵢ₊₁)
Lᵢ = span length i, Aᵢ = area of M₀ diagram in span i
āᵢ = distance of centroid from left support

Solution Method

This app assembles the three-moment equations into a tridiagonal linear system and solves it using Gaussian elimination. The support moments Mᵢ are found first, then reactions and internal forces are computed span-by-span using superposition.

Boundary Conditions

Pin / Roller end:   M = 0
Fixed end:          M = unknown (extra equation)
Free end:           Q = 0, M = 0

Superposition

Within each span, Q(x) and M(x) are found by treating the span as a simply supported beam with the computed end moments applied as external moments, superimposed with the applied loads.

Frame — Theory

System

A rectangular portal frame consists of two columns and a rafter. Depending on the support conditions, the frame is statically determinate (pinned feet) or indeterminate (fixed feet).

Pinned Supports (statically determinate)

With pinned feet, 4 unknown reactions (H_A, V_A, H_B, V_B) and 3 equilibrium equations + 1 hinge condition → solvable directly.

ΣM_A = 0 → V_B · b = ΣM_loads_about_A
ΣF_y = 0 → V_A = ΣF_vert − V_B
ΣF_x = 0 → H_A + H_B = ΣF_horiz
ΣM_crown = 0 → H_A · h = V_A · b/2 − ΣM_left
Crown = top of left column

Fixed Supports (3× statically indeterminate)

With fixed feet, 6 unknowns (H, V, M at each support). Solved using the stiffness method — the horizontal thrust H is the primary unknown, found from the compatibility condition (zero horizontal displacement at rafter level).

H = ( Σq·b²/8 + ΣF·a·(b−a)/b ) / ( h + b/6·EI_col/EI_raf )
Simplified for uniform EI (moment distribution)

Internal Forces

M, Q and N are computed member by member (left column, rafter, right column) using equilibrium from the support upward.

Column: N = V, Q = H, M = H·x − M_foot
Rafter: N = H, Q = V − q·x, M = M_top + V·x − q·x²/2
